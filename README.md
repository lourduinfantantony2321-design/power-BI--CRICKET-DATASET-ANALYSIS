# 🏏 Cricket Data Analytics Dashboard – Power BI Project

## 📌 Project Overview

This project is a **Cricket Data Analytics Dashboard** created using **Power BI** to analyze player performance, wicket statistics, batting records, and six-hitting patterns.

The dashboard provides interactive visualizations that help users understand cricket player statistics through charts, tables, and performance comparisons.

---

## 📊 Dashboard Features

### 🔹 Wicket Analysis

* Wickets taken by wicket method
* Bowling performance comparison
* Dismissal type distribution

### 🔹 Batting Analysis

* Total runs scored by players
* Number of sixes hit by each player
* Top-performing batsmen visualization

### 🔹 Player Performance Insights

* Player-wise comparison charts
* Interactive filtering and sorting
* Performance summary tables

---

## 🛠️ Tools & Technologies Used

* **Power BI** – Data visualization & dashboard creation
* **Excel / CSV Dataset** – Cricket statistics dataset
* **Data Cleaning & Transformation** – Power Query
* **DAX Functions** – Calculated measures and KPIs
